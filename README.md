# Backtest Visualizer

**▶ Try it online: [https://omri-n6gdp.github.io/backtest-visualizer/](https://omri-n6gdp.github.io/backtest-visualizer/)** (works on phones too)

Visualise backtest results: equity curve, drawdown, Sharpe and monthly returns.

## How to use

Double-click **`index.html`** (or drag it into Chrome or Safari). Nothing to install.

## Files

- `index.html`: the whole app (HTML, CSS and JavaScript in one file)
